1.哪些寄存器包含函数参数？例如，main 调用 printf 时哪个寄存器保存了 13？

RISC-V 使用 a0~a7 共 8 个寄存器传递函数参数。
在 main 调用 printf 时（地址 0x38 的 jalr 指令），参数传递如下：
a0 保存格式字符串 "%d %d\n" 的地址
a1 保存 12（即 f(8)+1 的结果，因为 f(8)=g(8)=8+3=11，+1=12）
a2 保存 13
所以 13 保存在寄存器 a2 中。


2.main 的汇编代码中，对 f 的调用在哪里？对 g 的调用在哪里？

在 main 的汇编代码中，没有显式的 jal 或 jalr 调用 f 和 g 的指令。
因为 f 和 g 都是非常简单的函数（仅执行加法），编译器将它们内联（inline）了。
在 main 中，直接计算了 f(8)+1 = (8+3)+1 = 12，然后作为第二个参数传给 printf（保存在 a1 中）。
汇编代码中只看到 li a1, 12，没有看到 jal f 或 jal g 的调用指令。


3.printf 函数的地址是什么？

从 call.asm 中可以看到，printf 函数的标签在：
000000000000064e <printf>
所以 printf 的地址是 0x64e。
在运行时，实际地址为 0x8000... + 0x64e。


4.在 main 中执行 jalr 到 printf 之后，寄存器 ra 中的值是什么？

在地址 0x38 处执行 jalr 调用 printf：
  0000000000000038: 00000097  auipc ra,0x0
  000000000000003c: 616080e7  jalr 1558(ra) # 64e <printf>
jalr 指令会将下一条指令的地址（PC + 4）存入 ra。
下一条指令在地址 0x40（即 main 中调用 exit(0) 的位置），所以 ra 的值是 0x40（相对于程序加载基址）。
实际运行时 ra = 0x8000... + 0x40。


5.运行给定代码的输出是什么？如果 RISC-V 是大端序，i 应设为什么值？57616 需要改变吗？
代码：
  unsigned int i = 0x00646c72;
  printf("H%x Wo%s", 57616, &i);

0x00646c72 在小端序内存中存储为：72 6c 64 00
ASCII 对应字符：'r' 'l' 'd' '\0'
所以 &i 指向的字符串是 "rld"。

57616 的十六进制为 0xe110，%x 输出 "e110"。

因此输出为：He110 World

如果 RISC-V 是大端序：
i 应设置为 0x726c6400（即 'r' 'l' 'd' '\0' 的大端字节序排列）
57616 是数值常量，不受大小端影响，不需要改变


6.以下代码会输出什么（y= 后面）？为什么？
代码：
  printf("x=%d y=%d", 3);

输出为：x=3 y=<随机值>

原因是 printf 期望两个 %d 对应的 int 参数，但实际只提供了一个参数。
第二个 %d 会从栈上读取未初始化的数据（或某个寄存器中的随机值），导致输出不确定。
这是 C 语言的未定义行为，具体输出的值取决于编译器优化、栈布局和运行时状态。
